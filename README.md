# 🌟 Advanced MERN B2B Realtime Collaboration Platform - Kano


## 🗝️ Key Features: 👇

* 🔐 Authentication (Email + Password with JWT, Google)
* 🏢 Multi-tenant Workspaces
* 👥 Teams & Members
* ✉️ Invite Members by Email (Resend)
* 🛡️ Roles & Permissions
* 📋 Boards — List & Grid View
* ⭐ Starred & Recent Boards
* 🧩 Board Templates
* 🎨 Miro-style Canvas (React Flow)
* 📝 Sticky Notes, Text & Shapes
* 🔗 Connectors & Frames
* ✏️ Pen, Highlighter & Eraser
* 🖼️ Image Upload
* 👀 Realtime Collaboration (Liveblocks)
* 🖱️ Live Cursors & Presence
* 💬 Comments on the Canvas
* 🤖 AI Agent on the Board
* 🧠 AI Agent Tools — Notes, Flowcharts, Roadmaps, Drawings
* 🟡 AI Agent Presence & Live Status
* 💡 Streaming AI Chat (Liveblocks Feeds)
* 🎯 Select Objects as AI Context
* ⏪ Version History Snapshots
* 🌗 Light & Dark Mode
* 🌐 Built with MERN Stack (Node.js, MongoDB, React, TypeScript)
